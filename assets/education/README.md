# Educational tissue comparisons

Created with the built-in image generation tool for BREATHE on 2026-09-08.
These are AI-generated illustrative cutaways, not histology photographs or clinical scans. Tissue dimensions, cellular detail and microvasculature are simplified/exaggerated for legibility. Left is the reference tissue; right depicts chronic disease. They do not depict the effects of four individual puffs.

- `airway-comparison.png`: open airway vs inflamed, mucus-obstructed airway.
- `alveoli-comparison.png`: intact septa vs merged air spaces in emphysema.
- `gas-exchange-comparison.png`: intact capillary-bearing walls vs reduced exchange surface.

Image size: 1536 × 1024. The originals remain in the Codex generated_images directory. All website images are local project copies and use lazy loading.

Supporting health references:
- https://www.nhlbi.nih.gov/health/copd
- https://www.nhlbi.nih.gov/health/lungs
- https://www.cdc.gov/tobacco/about/cigarettes-and-copd.html

Numbered callouts, captions and explanations are HTML, not baked into the artwork. `education.js` enlarges each comparison in a native dialog with its labels and structure key, supporting Escape and a close button.

## Blood illustration
`red-blood-cells.png`: generated on 2026-09-08 with the built-in image tool, 1536 × 1024. Biconcave red blood cells in an illustrative vessel cutaway. It does not depict measured carbon monoxide exposure or a specific patient's blood. Molecules and oxygen changes are explained in adjacent HTML rather than encoded as literal visible changes in blood colour.
Source: https://www.cdc.gov/tobacco/data_statistics/sgr/2004/pdfs/chapter3.pdf
